# AI4Everyone

> 零门槛拥抱智能时代

AI 正在重塑每个人与技术的关系——不只是工程师，也包括设计师、产品经理、学生和创业者。这个项目收集和整理高质量的 AI 技术文档，帮助不同背景的人快速理解、选择和使用 AI 工具与架构。

## 为什么做这个

AI 工具和框架的迭代速度远超传统软件。大多数人面对的信息要么是营销话术，要么是碎片化的技术推文，很难形成系统认知。这个项目试图提供一个中间地带：

- **准确**：所有技术声明尽可能追溯官方文档和一手来源
- **完整**：横向覆盖多个工具/技术，纵向从概念到实践
- **可操作**：不是"了解一下"，而是能帮你做出选择
